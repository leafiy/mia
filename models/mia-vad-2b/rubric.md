# Mia 多维情绪标注口径 v1.1

给每条中文短文本标 8 个字段。只看文本本身，判断的是**作者（说话人）自己表达的情绪**：转述的新闻事件、别人的话，作者没表态就不算作者的情绪；反讽、阴阳怪气按作者的实际意思判。

| 字段 | 取值 | 怎么判 |
|---|---|---|
| `u` 可用 | 1 / 0 | 0 = 乱码、纯数字、时间戳、编号、表格或报表残片、商品标签串、机器模板、去掉虚词后的词串、中文字数不到一半（以外文为主）、看不出意思的残句。为 0 时其余字段填 null。 |
| `s` 整体态度 | 负面 / 中性 / 正面 | 负面 = 不满、失望、批评、愤怒、担忧、厌恶、贬损；正面 = 满意、赞赏、喜爱、愉快、感谢、期待、推荐；中性 = 客观陈述、说明、提问、叙述、报道，**褒贬并存、无法归为一方的也算中性**。 |
| `v` 效价 | -3 到 3 的整数 | -3 极强负面（绝望、暴怒、极度厌恶）；-2 明显负面（不满、失望、生气）；-1 轻微负面（小抱怨、略遗憾）；0 没有倾向或褒贬相抵；1 轻微正面（还行、挺好）；2 明显正面（满意、喜欢）；3 极强正面（狂喜、强烈推荐、感动落泪）。 |
| `a` 唤醒度 | 0 到 4 的整数 | 情绪的激活程度，和好坏无关。0 平静无波澜；1 低；2 中；3 高；4 极高。例句见下。 |
| `d` 支配度 | 0 到 4 的整数 | 作者对所说之事的掌控感、主动性。0 无力；1 偏被动；2 看不出或居中；3 偏主动；4 强势。例句见下。 |
| `e` 主导情绪 | 喜悦 / 愤怒 / 悲伤 / 恐惧 / 惊讶 / 厌恶 / 无明显情绪 | 只能从这 7 个里选一个，不能写别的词。满意、喜欢、感激、期待、自豪、被逗乐归喜悦；不满并带指责、生气归愤怒；失望、遗憾、难过、委屈、哀悼（不带指责）归悲伤；担心、焦虑、害怕归恐惧；意外、震惊归惊讶；嫌弃、恶心、鄙视、嘲讽归厌恶。有几种情绪时选最主要的一种。 |
| `i` 强度 | 0 到 3 的整数 | 主导情绪有多强。0 无；1 弱；2 中；3 强。 |

**唤醒度例句（自拟）：**

- 0：「明天上午九点在三楼开会。」
- 1：「味道还可以，下次也许还会来。」
- 2：「房间很干净，前台也很耐心，住得挺满意。」
- 3：「太好看了吧！一定要去现场看一次！」
- 4：「气死我了！！！什么破店，再也不来了！！」

**支配度例句（自拟）：**

- 0：「求求谁来帮帮我，真的撑不下去了。」
- 1：「又被临时通知加班，没办法，只能认了。」
- 2：「明天上午九点在三楼开会。」（客观陈述一律给 2）
- 3：「耳机音质不错，建议把降噪再做好一点。」
- 4：「今天之内给我退款，不然就投诉到底。」

**容易分歧的几种情况：**

- **广告、推广、商品标题**：作者在推销而不是表达自己的感受。有明确夸赞或推荐的，`s` 判正面、`v` 取 1；`e` 判无明显情绪、`i` 取 0，`a` 不超过 1。只是商品名或卖点词堆在一起的，`u` 判 0。
- **新闻标题、报道**：作者没表态的判中性、无明显情绪，`a` 取 0 或 1，`d` 取 2。用褒贬词定调的（如「正能量」「冲上第一」），按措辞判正面或负面，`i` 不超过 1。
- **悼念**：以哀悼、惋惜为主的，`s` 判负面、`e` 判悲伤。同时带愤怒或诅咒的（如要求严惩凶手），`e` 判愤怒。只有称颂、没有哀伤字眼的，判正面。
- **只有笑声或表情词**（如「哈哈哈哈」）：`u` 取 1，`s` 判正面，`e` 判喜悦，`a` 至少 2。
- **反讽**：按实际意思判。用反话表达嫌弃、鄙视的归厌恶；用反话抱怨并带指责的归愤怒。
- **褒贬并存**：`s` 判中性，`v` 按哪一边略重取 -1、0 或 1；`e` 和 `i` 按更强的那一边。
- **叙事、小说片段**：只判作者笔调本身带出的情绪，不判人物的情绪。人物再激动，作者只是平铺直叙的，按中性、无明显情绪判。

**字段之间必须自洽：**

- `s` 为正面时 `v` ≥ 1；`s` 为负面时 `v` ≤ -1；`s` 为中性时 `v` 在 -1 到 1 之间。
- `e` 为无明显情绪当且仅当 `i` = 0；此时 `a` 一般为 0 或 1。
- 强度和唤醒度是两回事：深深的悲伤可以是强度 3、唤醒度 1。

**输出：** 每条一行 JSON，字段按上表缩写，`id` 原样带回，例如：

```
{"id": "p0001", "u": 1, "s": "负面", "v": -2, "a": 3, "d": 3, "e": "愤怒", "i": 2}
{"id": "p0002", "u": 0, "s": null, "v": null, "a": null, "d": null, "e": null, "i": null}
```

## v1.2 补充（金标核对后统一，2026-10-25）

1. **负面情绪怎么分**
   - 愤怒：带火气，冲着具体的人或机构（商家、管理方、学校、政府、球员、某个人）指责、质问、骂、要求追责。
   - 厌恶：不带火气的批评和嫌弃，冲着东西本身（难用、做工差、不值、脏、臭、难吃、性价比低），以及鄙视、嘲讽、阴阳怪气。
   - 悲伤：失望、遗憾、可惜、委屈、心疼、难过，重点在自己落空或替别人难过，而不是挑对象的毛病。
   - 只列缺点、说「不满意」但口气平淡的（如「最不满意：油耗偏高」「缺点：后排窄」）：`s` 负面、`v` -1、`e` 无明显情绪、`i` 0、`a` 0 或 1。说了不满意、列了缺点就算负面，不判中性。
2. **正面的意外**：「没想到这么好吃」「居然超出预期」以夸为主，判喜悦。只有意外本身是重点（震惊、不敢相信、怎么会这样，看不出褒贬或褒贬是次要的）才判惊讶。「没想到这么差」按第 1 条判。
3. **谁的情绪**：真人讲自己的经历，不管第几人称都按作者判。小说、故事片段（有人物、对白、文学化叙述）不管第几人称都只按笔调判，叙述者和人物的情绪不算。古典诗词按诗词本身抒发的情绪判。
4. **看剧落泪**：被温情、美好打动的，判正面、喜悦。因人物受苦、离别、死亡而难过的，判悲伤；同时夸作品、夸演技的，`s` 判正面、`v` 取 1，否则判负面。
5. **新闻里的负面事件**：作者没表态的，判中性、`v` 0、无明显情绪。用了带感情色彩的措辞（惨烈、令人痛心、可耻）才取 ±1，并按措辞判情绪。
6. **支配度（已撤回）**：曾试行「评价、推荐、下结论一律 3」，只改了金标、训练标签仍是 v1.1 的理解，金标和另两方的支配度相关从 0.60 掉到 0.51～0.54，已退回。支配度仍按 v1.1 的定义和例句判，不要套这一条。
7. **可用性**：开头带编号、日期、时间戳但正文读得懂的，`u` 1；几条评论拼在一起但每段读得懂的，`u` 1；以外文为主、只有用户名或地名、标签串、报表残片，`u` 0。
